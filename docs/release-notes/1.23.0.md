# v1.23.0

## API and MCP

- **Category type only:** a category's type is its `type` (Income, Expense or Transfer). The old `isIncome` field is gone: creating or updating a category with `isIncome` is refused, and category responses, the MCP `list_categories` tool and the joint-account category lists no longer include it. Send and read `type` (`categoryType` on a category) instead.
- **Rolling upgrade:** this release drops the database column the previous release still reads, so during a rolling update the pods of the previous release fail category requests until the rollout completes. A `Recreate` rollout avoids the overlap.
