AI, on your terms

Ask your finances a question

Bring your own provider — Claude, GPT, or a local Ollama model. Nothing leaves your server beyond what answers the question you asked.

Monize AI Assistant demo
  • ✔Multi-provider. Anthropic, OpenAI, Ollama, Ollama Cloud or any OpenAI-compatible endpoint, with a priority-based fallback chain.
  • ✔Eighteen tools. Transactions, accounts, categories, payees, budgets, upcoming bills, portfolio, capital gains, period comparison, report generation, charts and a calculator — plus guarded write tools for transactions, payees and securities.
  • ✔Streaming answers. Responses arrive token-by-token over Server-Sent Events.
  • ✔Keys stay encrypted. Per-user API keys sealed with AES-256-GCM; usage, tokens and cost tracked per request.
  • ✔Spending insights. Automatic anomaly, trend, subscription, new-recurring, budget-pace and seasonal detection.
  • ✔MCP server built in. Point Claude Desktop straight at your own ledger.
Migration

Bring the whole shoebox

Point Monize at a Microsoft Money .mny file or a Quicken QIF export and it reads the lot — accounts, splits, transfers, investments, price history, exchange rates and scheduled bills — then reconciles every balance against the source.

Self-hosting

Up and running in one command

Two containers and a Postgres database. Runs happily on a NAS, a VPS, or — like the author's — a Kubernetes cluster.
